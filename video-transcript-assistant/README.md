# ローカル文字起こし助手

素材動画（音声付き）を自分のPCだけで文字起こしする個人用ツールです。  
**クラウドへの文字起こし送信はありません。要約は外部AIサービス側で行ってください。**

## できること

1. 動画をドロップして文字起こし（Whisper）
2. **中断する**で途中停止
3. テキストを自由に編集
4. Markdown として `output/` に保存

## 使い方

1. `run.bat` をダブルクリック
2. ブラウザで http://127.0.0.1:7861
3. 動画をドロップ → **文字起こしする** → 必要なら編集 → **保存する**
4. 要約したいときは、保存したテキストを外部AIへ渡す

## 必要なもの

- Windows 64bit
- Python 3.12
- FFmpeg（`ffmpeg` が PATH にあること）
- whisper.cpp（`vendor/whisper/Release/whisper-cli.exe`）

## 注意

- タイムスタンプは付けません（本文のみ）
- 既定モデルは `small`。`large-v3` はCPUでは非常に遅いので非推奨
- 固有名詞の誤りは手直ししてください
